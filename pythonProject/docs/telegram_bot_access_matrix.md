# Telegram bot access matrix

## Roles

- `guest` — только базовый просмотр: прайсы, акции, график.
- `client` — просмотр своих данных и своей карточки клиента.
- `sales_rep` — работа со своими клиентами, карточками, просрочкой, переплатами и ТТН.
- `moderator` — урезанный админ: расширенный просмотр, проверка ТТН и уведомления о новых пользователях.
- `admin` — полный доступ.

## Notes

- Роль по умолчанию для неизвестного/неназначенного пользователя — `guest`.
- `client` не получает управляющие кнопки карточек клиента.
- Кнопка `🏢 Моя карточка` для `client` сразу открывает единственную назначенную карточку.
- Если доступ запрещён, бот показывает объяснение и возвращает пользователя в доступное меню.
